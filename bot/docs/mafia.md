# Мафия в текстовом чате

`!мафия` (или `/mafia`) в группе создаёт лобби. Участники нажимают «Вступить».
Перед вступлением каждый должен открыть личку бота и нажать Start. Если бот не
может написать участнику, место не занимается, кнопка ведёт в личку с правилами.
Создатель лобби тоже вступает кнопкой; он может быть ведущим без роли.

От 5 до 16 игроков. Начать — кнопкой «Начать» или `!мафия старт` (создатель).
Остановить — `!мафия стоп` (создатель или администратор Telegram-чата).
`!мафия правила` — правила; повторная `!мафия` — состояние и актуальные кнопки.
Одна партия на чат, один игрок одновременно в одной партии. В темах форума
сообщения партии остаются в исходной теме.

Роли случайны: одна мафия на 5–6 игроков, две на 7–10, три на 11–16;
один доктор, один комиссар, остальные мирные. Роли приходят только в личку.
Мафия знает состав своей команды. Если роли невозможно доставить всем,
партия отменяется и для следующей роли раздаются заново.

Ночь — 90 секунд. Мафия выбирает жертву среди не-мафии, доктор лечит
(включая себя), комиссар проверяет другого игрока и получает результат в личке.
Если голоса мафии разделились поровну, убийства нет. Лечение спасает цель мафии.
Действия одновременны: комиссар получает результат даже в ночь своей гибели.
День — 120 секунд обсуждения; создатель может раньше начать голосование кнопкой.
Голосование — 60 секунд, живые выбирают другого игрока или пропуск.
Единственный лидер голосования выбывает, при ничьей или победе пропуска — никто.
Отсутствующий голос не учитывается. Пока этап не закончился, выбор можно менять.
Ночь и голосование завершаются раньше, если все соответствующие игроки ответили.
Старые кнопки, посторонние и выбывшие игроки не могут вмешаться.
Роль выбывшего объявляется в группе; остальные роли раскрываются в конце.
Мирные выигрывают после устранения всей мафии; мафия — при равенстве с остальными.

Игровое выбывание не вызывает Telegram-мутов и не меняет дуэльные статусы.
Пустое лобби закрывается через 10 минут. Два круга без действий и голосов
закрывают заброшенную партию. Явный пропуск считается действием.

Состояние сохраняется в `database/mafia_sessions.db` (тот же Docker-том,
отдельно от персональных анкет). После перезапуска роли и выборы сохраняются,
текущий этап получает полный таймер, игрокам повторно отправляются роли
и актуальные кнопки. Роутер сам запускает и останавливает таймер через
startup/shutdown; `main.py` уже подключает `mafia_router`.

Проверка (из `bot/`, Python с зависимостями из requirements.txt):

```sh
python -m unittest discover -s tests -p test_mafia.py -v
```

Тесты используют временную SQLite и подменённый транспорт, без Telegram API,
без рабочего токена и без polling. Файлы для установки: `utils/mafia.py`,
`database/mafia_store.py`, `handlers/command_mafia.py`, `handlers/command_help.py`,
`handlers/command_profile.py`, `handlers/command_tracker.py`. После замены
нужна пересборка существующего контейнера; второй экземпляр polling не запускать.
